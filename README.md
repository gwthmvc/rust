# Rust Tutorials

A simple introduction to **Rust** built by following the official Rust getting started tutorial. This project sets up a basic application, demonstrating the core tools in the Rust ecosystem like `rustc` and `cargo`.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You need to have the Rust toolchain installed. If you haven't already, install it via [rustup](https://rustup.rs):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://rustup.rs | sh
```

### Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd your-project-name
   ```

2. **Build the project:**
   ```bash
   cargo build
   ```

3. **Run the application:**
   ```bash
   cargo run
   ```

## 🛠️ Built With

* [Rust](https://rust-lang.org) - The programming language used.
* [Cargo](https://rust-lang.org) - Rust's package manager and build system.
